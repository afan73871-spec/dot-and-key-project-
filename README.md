# 🧠 MarketMind AI
### Vibe Coders Hackathon Edition 3 — Dot & Key: Market Intelligence → Marketing Content

> **Turn any skincare product URL into a full marketing intelligence report + ready-to-launch ad creatives in under 60 seconds.**

---

## 🚀 Live Demo Flow
1. Paste a **Dot & Key / Minimalist / Nykaa product URL** → Extract real product metadata
2. Auto-generate **Competitor Clash** — real ratings, verbatim complaints, pricing gaps
3. Run **SWOT Analysis** powered by Gemini 2.5 Flash
4. Launch **Marketing Studio** — 1080×1080 ad creatives, Meta JSON payloads, ROI predictor

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Dark Navy `#0F172A` + Vivid Purple `#7C3AED`)
- **AI**: Gemini 2.5 Flash (market analysis, competitor intelligence)
- **Image Generation**: HTML5 Canvas compositing (1080×1080 ad creatives)
- **Icons**: Lucide React

## ⚙️ Setup

```bash
# 1. Clone
git clone https://github.com/afan73871-spec/dot-and-key-project-
cd dot-and-key-project-

# 2. Install dependencies
npm install

# 3. Add your API key
# Create .env.local in project root:
echo "VITE_GEMINI_API_KEY=your_gemini_api_key_here" > .env.local

# 4. Run dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
